## [0.1.0] - 2026-08-04

### Added

- Local-only CLI for creating separated competition repositories.
- Text/Markdown/JSON brief intake and structured known/unknown/risk extraction.
- Markdown and HTML deck, demo plan, pitch, and submission checklist generation.
- Claude Code and Codex skill synchronization from one canonical source.
- Strict external-skill registry policy with no approved third-party skills by default.
- Public repository documentation, security policy, CI, secret scanning, and readiness checks.
