# Plan a competition entry

1. Refuse to rank ideas until hard constraints are applied: eligibility, required technology, deadline, demonstrability, and compliance.
2. Map each judging criterion to a claim, visible evidence, demo moment, deliverable, and owner.
3. Prefer the smallest concept that communicates value in 30 seconds and completes one end-to-end flow.
4. Work backward from the submission deadline. Reserve time for a first complete demo, feature freeze, fallback capture, two rehearsals, URL verification, and early submission.
5. Mark authentication, billing, settings, admin UI, history, and multi-tenant behavior as omitted unless the brief requires them.
6. Define cut triggers before development. Remove optional work when a gate is late.
7. Recompute the plan when judging criteria, time, team size, or implementation evidence changes.
8. Never present a score as a prediction of winning or funding.

Use [references/evidence-map.md](references/evidence-map.md) for the planning record.
