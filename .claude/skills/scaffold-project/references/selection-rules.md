# Stack selection rules

- Prefer a public web URL when judges need instant access.
- Prefer server-rendered or static HTML over React for simple forms and reports.
- Use Python when the core work is numerical analysis, ML, or data processing.
- Use Expo only when a native device capability is part of the core proof.
- Add persistence only when data must survive the demo flow.
- Add realtime only when simultaneous coordination is visible in the core experience.
- Avoid unfamiliar infrastructure when the deadline is the dominant risk.
