# Release checklist

- Official rules rechecked after the last organizer update
- Eligibility, reuse, AI-tool, IP, and privacy rules confirmed
- Secret and personal-data scans passed
- Required technology visibly used
- Claims match implementation and evidence
- Dependencies pinned and licenses attributed
- Demo and fallback rehearsed
- Deck and pitch timed
- Repository and artifact visibility correct
- URLs reopened from a fresh session
- Submission receipt and final commit preserved
