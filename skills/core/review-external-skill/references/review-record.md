# Review record

Record:

- Candidate ID and purpose
- Source owner, repository, and full commit SHA
- Discovery source; mark GitHub Trending as discovery-only
- SPDX license and compatibility notes
- Files and dependencies reviewed
- Requested filesystem, shell, network, browser, secret, and account access
- Scanner names, versions, configuration, and raw results
- Manual findings and mitigations
- Reproduction steps in a disposable environment
- Trigger, negative-trigger, incomplete-input, and adversarial tests
- Independent reviewer records
- Human approver, approval date, and scope
- Removal and rollback procedure
