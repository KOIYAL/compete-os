# Compliance modes

## Strict

Use when rules are unknown, prior work may be prohibited, or same-day creation is required. The generated repository receives project instructions and planning records but no reusable skill folders or application starter code.

## Standard

Use after confirming that generic workflow guidance is allowed. The generated repository receives the five core delivery skills but no external-skill review capability and no application starter code.

## Reuse

Use only after confirming that reusable assets are permitted. All CompeteOS core skills may be copied. Application components still require explicit selection and license review.

No mode is a legal opinion. Preserve the organizer's exact wording and obtain clarification when a rule affects eligibility or intellectual property.
