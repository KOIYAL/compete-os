# Civic Access Challenge

- Build a working prototype that helps residents understand a public service.
- Teams must submit a public repository, a working URL, and a three-minute demo.
- Deadline: 2026-08-08 18:00 JST.
- Judging criteria: user value 30%, implementation 25%, originality 20%, demo quality 15%, sustainability 10%.
- Personal data must not be used in the demo.
- Existing open-source libraries are allowed with license attribution.
- The final presentation order will be announced on the day.
